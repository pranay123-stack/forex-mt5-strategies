==========================================
  Steps to Login to ICMarkets in MT5
==========================================

Understanding the Setup:
  ICMarkets  → Broker (holds your money, provides market access)
  MT5        → Trading software (desktop app, runs your EAs)
  cTrader    → Alternative trading software (browser-based, EAs don't work here)

  Your EAs (.ex5 files) only work on MT5.

==========================================
  Option A: Demo Account Login
==========================================

1. Open MT5
2. Go to File → Open an Account
3. Search for "ICMarkets" or type "ICMarketsSC"
4. Select server: ICMarketsSC-Demo
5. Choose "Login to an existing account"
6. Enter:
     Login:    your demo account number (e.g., 52688756)
     Password: your demo password
7. Click OK
8. Verify: bottom-right corner shows green bar with ping (e.g., 12ms)
           NOT "No connection"

==========================================
  Option B: Live Account Login
==========================================

1. Open MT5
2. Go to File → Open an Account
3. Search for "ICMarkets" or type "ICMarketsSC"
4. Select server: ICMarketsSC-Live   *** NOT Demo! ***
5. Choose "Login to an existing account"
6. Enter:
     Login:    your live account number
     Password: your live password
7. Click OK
8. Verify: bottom-right shows green bar
           Title bar shows "Live" account

==========================================
  How to Verify Connection
==========================================

  What to check       Where                    Good                    Bad
  ---------------     -------------------      -------------------     ------------------
  Connection          Bottom-right corner      Green bar with XX ms    "No connection" / red
  Account type        Window title bar         Shows "Demo" or "Live"  Nothing
  Balance             Trade tab (bottom)       Shows your deposit      $0 or empty
  Server              Bottom-right             ICMarketsSC-Demo/Live   Wrong server

==========================================
  If Server Not Found
==========================================

1. File → Open an Account
2. Click "+" or "Add broker"
3. Type: ICMarketsSC and press Enter
4. MT5 will download the server list
5. Now select Demo or Live server from the list

==========================================
  ICMarkets Server Names
==========================================

  Demo:  ICMarketsSC-Demo
  Live:  ICMarketsSC-Live

  Note: Server names may vary slightly depending on your region.
  Other possible servers:
    ICMarketsEU-Demo / ICMarketsEU-Live  (for EU clients)
    ICMarkets-Demo / ICMarkets-Live      (older naming)

  Use the server name shown in your ICMarkets Client Portal
  under your account details.

==========================================
  Where to Find Your Credentials
==========================================

1. Log in to ICMarkets Client Portal: secure.icmarkets.com
2. Go to Accounts section
3. Click on your Demo or Live account
4. You will see:
     - Account Number (this is your Login)
     - Server Name
     - Password (sent via email when account was created)
5. If you forgot your password:
     - Click "Reset Password" in the portal
     - Or contact ICMarkets support

==========================================
  Switching Between Demo and Live
==========================================

You can have BOTH Demo and Live accounts open in MT5:

Method 1: Switch accounts
  - File → Login to Trade Account
  - Enter different credentials

Method 2: Run two MT5 instances
  - Install MT5 in two different folders
  - Run one for Demo, one for Live
  - This way you can monitor both simultaneously

==========================================
  After Successful Login - Next Steps
==========================================

For Demo (Paper Trading):
  1. Open chart for your symbol (e.g., EURUSD)
  2. Set correct timeframe
  3. Enable Algo Trading (green button in toolbar)
  4. Drag EA onto chart
  5. Configure inputs → OK
  6. Monitor for 1-2 weeks

For Live (Real Money):
  1. Set up VPS first (EA must run 24/5)
  2. Open chart for your symbol
  3. Set correct timeframe
  4. Enable Algo Trading
  5. Drag EA onto chart
  6. Use MINIMUM lot size (0.01)
  7. Set conservative risk parameters
  8. Monitor closely for first few days
