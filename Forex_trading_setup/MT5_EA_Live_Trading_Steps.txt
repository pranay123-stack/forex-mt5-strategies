There are 2 modes:
  A) Paper Trading (Demo Account) → fake money, real market data
  B) Live Trading (Real Account)  → real money, real market data

Always start with Paper Trading first to validate your EA in live market conditions
before risking real money.

==========================================
  A) PAPER TRADING (Demo Account)
==========================================

Step 1: Create a Demo Account
------------------------------
- Open MT5 → File → Open an Account
- Select your broker (e.g., ICMarkets, Pepperstone, FTMO)
- Choose "Open a demo account"
- Set:
    * Account type (Standard, Raw Spread, etc.)
    * Leverage (e.g., 1:100)
    * Initial deposit (e.g., $10,000)
    * Currency (USD)
- Click "Next" → account credentials are created
- Note down: Login, Password, Server

Step 2: Compile and Copy the EA
-------------------------------
- Make sure your EA is compiled (0 errors in MetaEditor)
- EA (.ex5 file) should be in: MQL5/Experts/
- Include files (.mqh) should be in: MQL5/Include/

Step 3: Open a Chart
--------------------
- Open a chart for the symbol your EA trades (e.g., EURUSD)
- Set the correct timeframe (e.g., M15, H1) matching your EA's design
- Make sure "Algo Trading" button in the toolbar is ENABLED (green icon)

Step 4: Attach EA to Chart
--------------------------
- In the Navigator panel (Ctrl+N), find your EA under Expert Advisors
- Drag and drop it onto the chart
  OR double-click the EA name
- A settings dialog appears:
    * "Common" tab:
        - Check "Allow Algo Trading"
        - Check "Allow DLL imports" (only if EA requires it)
    * "Inputs" tab:
        - Set your parameters (lot size, SL, TP, etc.)
        - For paper trading, use small lot sizes (0.01)
    * Click "OK"

Step 5: Verify EA is Running
-----------------------------
- Top-right corner of the chart should show the EA name with a smiley face :)
- If it shows a frowning face :( → Algo Trading is disabled, click the button in toolbar
- Check the "Experts" tab at the bottom for initialization messages
- Check the "Journal" tab for any errors

Step 6: Monitor the EA
-----------------------
- Let the EA run on the demo account
- Monitor via:
    * "Trade" tab (bottom) → shows open positions
    * "History" tab (bottom) → shows closed trades
    * "Experts" tab → shows EA log messages
- Run for at least 1-2 weeks to validate performance
- Compare demo results with backtest results

Step 7: Evaluate Paper Trading Results
---------------------------------------
- After 1-2 weeks, check:
    * Does it match backtest performance?
    * Any unexpected behavior?
    * Slippage issues?
    * Spread sensitivity?
    * Execution speed OK?
- If results are acceptable → proceed to live trading
- If not → go back, fix the EA, re-backtest, re-paper trade

==========================================
  B) LIVE TRADING (Real Money)
==========================================

*** WARNING: Only proceed after successful paper trading ***

Step 1: Open a Live Account with a Broker
------------------------------------------
- Choose a regulated broker (e.g., ICMarkets, Pepperstone, OANDA)
- Factors to consider:
    * Regulation (ASIC, FCA, CySEC)
    * Spreads (raw spread preferred for EAs)
    * Commission fees
    * Execution speed
    * VPS availability
    * Leverage offered
- Complete KYC (ID verification, proof of address)
- Fund the account (start SMALL - e.g., $500-$1000)

Step 2: Connect MT5 to Live Account
------------------------------------
- Open MT5 → File → Login to Trade Account
- Enter: Login, Password, Server (from your broker)
- Verify connection: bottom-right corner shows connection speed (not "No connection")

Step 3: Set Up VPS (HIGHLY RECOMMENDED)
----------------------------------------
- EA needs to run 24/5 (forex market hours) without interruption
- Options:
    * MT5 built-in VPS: right-click EA → "Register a Virtual Server"
    * Third-party VPS: ForexVPS, Beeks, Amazon AWS
    * Your own server running 24/7
- Install MT5 on the VPS
- Copy your EA files to the VPS MT5 installation

Step 4: Attach EA to Live Chart
-------------------------------
- Same process as paper trading (Step 4 above)
- IMPORTANT differences for live:
    * Start with MINIMUM lot size (0.01)
    * Set conservative risk parameters
    * Enable all safety features (max drawdown, max trades, etc.)
    * Double-check SL and TP values

Step 5: Risk Management Checklist (BEFORE starting)
----------------------------------------------------
[ ] Lot size is small (0.01 or risk-based)
[ ] Stop Loss is set for every trade
[ ] Maximum drawdown limit is configured
[ ] Maximum daily trades limit is set
[ ] Maximum open positions limit is set
[ ] Spread filter is enabled
[ ] Session/time filter is correct
[ ] Magic number is unique (no conflicts with other EAs)
[ ] Account has sufficient margin for the lot size
[ ] News filter is enabled (if available)

Step 6: Monitor Live Trading
-----------------------------
- First few days: watch closely, check every few hours
- Monitor via:
    * MT5 Trade tab → open positions
    * MT5 History tab → closed trades
    * MT5 mobile app → monitor on the go
    * Broker's web portal → account overview
- Set up alerts:
    * Email notifications for trades
    * Push notifications to MT5 mobile app
    * Telegram bot alerts (if EA supports it)

Step 7: Scaling Up
------------------
- Week 1-2:  Minimum lot size (0.01), observe
- Week 3-4:  If profitable, slightly increase lot size
- Month 2:   Gradually increase to target lot size
- Never risk more than 1-2% per trade
- Never increase lot size after a losing streak

==========================================
  Key Differences: Backtest vs Paper vs Live
==========================================

                    Backtest        Paper (Demo)     Live (Real)
                    ----------      ------------     -----------
Money:              Simulated       Fake             Real
Market Data:        Historical      Real-time        Real-time
Execution:          Instant         Near-instant     Slippage possible
Spreads:            Fixed/Modeled   Real             Real
Emotions:           None            None             High
Risk:               None            None             Real loss possible
Duration:           Minutes         Days/Weeks       Ongoing
Purpose:            Strategy test   Live validation  Profit/income

==========================================
  Common Mistakes to Avoid
==========================================

1. NEVER go live without paper trading first
2. NEVER risk more than you can afford to lose
3. NEVER run EA without a VPS (your PC can crash/disconnect)
4. NEVER use maximum leverage with an EA
5. NEVER increase lot size after losses (revenge trading)
6. NEVER run multiple EAs on the same symbol with same magic number
7. NEVER ignore broker fees/commissions in your calculations
8. ALWAYS have a kill switch (max drawdown that stops the EA)
9. ALWAYS monitor your EA daily, even if automated
10. ALWAYS keep your MT5 and EA updated
